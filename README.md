# Healthcare_eda

# Exploratory Data Analysis – Medical Appointment No-Show Prediction

=>Conducted an end-to-end Exploratory Data Analysis (EDA) on a real-world healthcare dataset containing 110,000+ patient appointment records to identify factors influencing appointment no-shows.

=>Performed data cleaning and preprocessing, including datetime standardization, feature renaming, age binning, and weekday extraction.

=>Verified data quality by confirming zero missing values, eliminating the need for imputation.

=>Engineered meaningful features such as appointment weekday, scheduled weekday, and age groups to enhance interpretability.

=>Analyzed target imbalance, identifying that ~80% of patients attended appointments while ~20% were no-shows.

=>Conducted univariate, bivariate, and correlation analysis using Pandas, NumPy, Matplotlib, and Seaborn.

=>Converted categorical variables into dummy variables and analyzed their correlation with the target variable.

# Discovered key behavioral insights:

=>Patients with hypertension and diabetes showed higher attendance rates than healthy patients.

=>SMS reminders did not improve attendance; patients receiving SMS had a lower show-up rate.

=>Children (0–1 years) had significantly higher appointment adherence.

=>Scholarship recipients exhibited slightly lower attendance compared to non-recipients.

=>No appointments occurred on Sundays, with very limited scheduling on Saturdays.

=>Visualized insights using count plots, box plots, bar charts, and heatmaps to communicate findings effectively.

=>Prepared the dataset for machine learning modeling by encoding categorical features and validating feature correlations.

# Tools & Technologies:
Python, Pandas, NumPy, Matplotlib, Seaborn, Data Visualization, Feature Engineering, Healthcare Analytics
